# Mounter

Співробітники, замовники, склад бригади, об’єкти,
вироби, фото та примітки зберігаються в пам’яті пристрою.

Перед відкриттям меню потрібна успішно збережена NFC-відмітка «Прихід» у app-test.
LOCAL не потрібен для відкриття меню. Таймер «Робочі години» показує час поточної
зміни та завершується після наступної відмітки тією самою карткою.
Інструкція встановлення змін для додатка відміток і LOCAL:
[Відмітки перед відкриттям Mounter](../attendance-integration/README.md).

- У вкладці «Бригада» введіть ПІБ. Пошук одразу показує збіги з локального списку.
  Якщо збігів немає, натисніть «Додати співробітника»: людина збережеться
  у списку й додасться до бригади.
- Зняття checkbox прибирає співробітника зі складу бригади. Його можна знайти
  знову через пошук і повернути до бригади.
- Під час створення об’єкта виберіть замовника з локальних результатів пошуку.
  Якщо замовника немає, введіть його назву та натисніть «Додати замовника»,
  потім «Створити».
- Регістр літер та зайві пробіли не створюють дублікатів імен.
- Кожен виріб має назву, окреме поле «Характеристики» для довільного тексту,
  багато фото та одну спільну примітку. Характеристики зберігаються автоматично
  та відображаються у картці об’єкта під назвою виробу.

При оновленні зберігаються наявні об’єкти та обрані співробітники.
Локальний список замовників також заповнюється з наявних об’єктів.
Пошук охоплює лише записи, збережені на цьому пристрої.
