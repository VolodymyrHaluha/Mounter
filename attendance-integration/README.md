# Передавання NFC-картки до APP-TEST

Mounter локально починає або завершує відлік на скануванні картки й передає її
в APP-TEST для звичайної обробки. Він не читає ContentProvider, серверні статуси
або історію й не взаємодіє з LOCAL/GLOBAL чи БД.
[Поточна поведінка](../docs/authoritative-attendance.md).

Файли цієї папки — матеріали попередньої серверної інтеграції APP-TEST.
Вони не включені до Android-збірки Mounter. Для його таймера не потрібні
скрипти, міграції чи серверні підтвердження. APP-TEST продовжує працювати
й передавати відмітки на сервер за власними правилами.
