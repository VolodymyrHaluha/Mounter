# Узгоджений контракт NFC-доступу v2

Повідомлення «Оновіть APP-TEST: потрібен сукупний стан карток» було спричинене
несумісністю: фактичний provider APP-TEST повертав тільки одну глобальну подію.
Це не ознака відсутності підключення до LOCAL. Виправлення тепер внесено в
**фактичний код обох додатків**, а не лише в шаблони цієї папки.

Остаточну дію й часові мітки визначає LOCAL. APP-TEST зберігає постійні стани
карток, непідтверджені UUID та завершені зміни. GLOBAL віддає авторизовані
результати LOCAL через кеш; успішне приймання події GLOBAL не відкриває доступ.

Докладний серверний контракт, міграції й порядок встановлення:
[APP-TEST: authoritative-attendance.md](https://github.com/VolodymyrHaluha/APP-TEST/blob/codex-authoritative-card-attendance/docs/authoritative-attendance.md).

Установіть парні версії APP-TEST/Mounter **поверх** наявних APK з тими самими
ключами підпису, після оновлення LOCAL/GLOBAL. applicationId збережено,
versionCode підвищено до 2. Дані об’єктів, бригади, виробів, фото Mounter,
налаштування й старі NFC-записи не очищуються.

Authority залишається `com.example.app.mounter.attendance`. `/cards` повертає
один рядок на картку; `/history` — попередні завершені зміни. `/status` віддає
атомарний знімок JSON `cards` та `history`, `generation` і `contract_version=2`.
Mounter використовує цей знімок. Несумісний формат, порожній кеш і тимчасова
помилка читання мають різні результати. Немає ручного обходу доступу.

Вихід А за активної Б не скидає спільний стан; повторна перевірка не показує
проміжного блокування. Вихід останньої картки закриває всю композицію MounterApp,
включно з об’єктами, бригадою, деталями й діалогами. NFC-картки одного employee_id
представляють одну серверну зміну; різні працівники мають незалежні години.

«Робочі години» показують активні картки першими, завершені з ✓, очікувані з
позначкою LOCAL. Верхня панель компактна, усі картки й попередні зміни доступні
в прокручуваному діалозі. Таймери використовують серверні timestamps і один
UI-clock; вони не обнуляються опівночі чи при перезапуску.

Kotlin-шаблони цієї папки оновлено як посилання на фактичний APP-TEST-код.
Застарілі скрипти вставляння коду зупиняються без змін: вони не можуть безпечно
накласти нове сховище та серверний контракт на довільну стару інтеграцію.
Використовуйте оновлений повний APP-TEST, не старий installer.

Робочий сервер і пристрій не оновлюються автоматично зі змінами GitHub.
Перевірка реальних LOCAL/GLOBAL відповідей, міграцій у PostgreSQL та сценаріїв
перезапуску Android потрібна після розгортання.
