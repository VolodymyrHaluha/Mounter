# Інтеграція APP-TEST

Поточний Mounter лише отримує імена й час приходу/виходу від APP-TEST.
Підключення до БД та підтвердження LOCAL/GLOBAL у Mounter не потрібні.
[Поточний формат даних](../docs/authoritative-attendance.md).

Файли цієї папки — матеріали попередньої серверної інтеграції APP-TEST.
Вони не включені до Android-збірки Mounter. Для роботи оновленого Mounter
не потрібно запускати ці скрипти, установлювати серверні підтвердження або
виконувати міграції БД. Фактичний APP-TEST має надавати імена й часові мітки
відміток через наявний ContentProvider.
